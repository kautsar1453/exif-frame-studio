Pasang App & Build .APK Mandiri

EXIF Studio File Lokal HP

Chrome membatasi tombol instal otomatis pada alamat file://. Gunakan menu browser (⋮) → "Tambahkan ke layar utama" atau jalankan via HTTPS/localhost.

1. Tambah Ikon ke Layar Utama HP (Instan)

  • 1 Android (Chrome / Edge / Samsung): Ketuk menu titik tiga (⋮) di pojok kanan atas browser, lalu pilih "Tambahkan ke layar utama" atau "Instal aplikasi".
  • 2 iPhone / iPad (Safari): Ketuk ikon Bagikan (⍐) di bawah layar, lalu pilih "Tambah ke Layar Utama".

2. Unduh Bahan Proyek Android (.APK)

Unduh kedua file berikut ke dalam satu folder yang sama (sudah otomatis menyertakan workflow .github/workflows/build-apk.yml):

3. Cara Build .APK Tanpa Android Studio

  • A Via GitHub Actions (Gratis di Cloud — Tanpa Instal SDK):
    Jalankan bash Bangun-EXIF-Studio-Android.sh, lalu unggah isi folder EXIF-Frame-Studio-Android ke repositori GitHub baru. Buka tab Actions di GitHub → pilih workflow Build Android APK → unduh file EXIF-Frame-Studio-APK di bagian Artifacts.
  • B Via Termux Langsung di HP Android (Tanpa PC):
    Letakkan kedua file di folder Download, lalu jalankan di Termux: pkg install openjdk-17 gradle -y && cd ~/storage/downloads && bash Bangun-EXIF-Studio-Android.sh && cd EXIF-Frame-Studio-Android && gradle assembleDebug
  • C Via Gradle CLI / Android Studio di PC:
    Masuk ke folder EXIF-Frame-Studio-Android dan jalankan gradle assembleDebug. File APK siap pasang berada di app/build/outputs/apk/debug/app-debug.apk.
